# Mobydeck Dashboard

Статический демонстрационный дашборд деплой-платформы **Mobydeck**.  
Все данные — клиентский мок (JS), никаких внешних сетевых запросов нет.  
Деплоится через kaniko-сборку: `nginx:1.27-alpine`, слушает порт **8080**.

## Что видно на странице

- **KPI-карточки** — активные деплои, онлайн-пользователи, запросы, аптайм; числа анимированно растут при загрузке и периодически меняются.
- **График** — запросы за последний час (инлайновый SVG, без библиотек), обновляется каждые 8 секунд.
- **Таблица приложений** — 8 записей со статус-бейджами (Running / Building / Failed / Pending) и мини-спарклайнами.
- **Лента активности** — новые события добавляются сверху каждые ~15–25 секунд.
- **Тосты** — уведомления о деплоях всплывают раз в ~10–20 секунд.
- **Живые часы** и счётчик онлайн-сессий с лёгкой флуктуацией.

## Локальный запуск

```bash
# Просто открыть в браузере (nginx не нужен для разработки)
open index.html

# Или через Python для корректных путей /assets/
python3 -m http.server 8080
# → http://localhost:8080
```

## Docker

```bash
# Сборка
docker build -t demo-frontend .

# Запуск
docker run --rm -p 8080:8080 demo-frontend
# → http://localhost:8080
```

## Деплой в Mobydeck

Достаточно указать репозиторий — платформа сама:
1. Запускает kaniko-сборку из `Dockerfile` в корне.
2. Загружает образ в registry.
3. Поднимает Deployment + Service + Ingress на порту **8080**.

Никаких переменных окружения и build-аргументов не требуется.
